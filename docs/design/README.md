Design de référence : Figma Make « Design professionnel multi-écrans »
https://www.figma.com/make/WoqSeG7dJL3yS32HQGfvV6/Design-professionnel-multi-%C3%A9crans

Source principale : `src/App.tsx` (écrans, composants, états) et `src/index.css` (tokens, breakpoints, mode sombre).
La maquette HTML `../maquette-communaute-le-revenu.html` reste la référence d'origine.

Identité visuelle : celle du site réel lerevenu.com (logo officiel, Playfair Display et Source Sans 3, palette bordeaux et rouge, fond crème), relevée dans ses feuilles de style. Le Figma et la maquette servent pour la structure des écrans.

Écarts assumés :
- icônes `lucide-react` remplacées par Hugeicons ;
- vues, « Résolu », votes, stats du hero et « Les plus lues » hors périmètre initial (bonus) ;
- contenu requis sans minimum de 20 caractères (règle du PDF).
