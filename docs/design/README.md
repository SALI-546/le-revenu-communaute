Référence de design : la maquette HTML fournie, `../maquette-communaute-le-revenu.html`, pour la structure des écrans (accueil, espaces, discussion, création, charte).

Identité visuelle : celle du site réel lerevenu.com (logo officiel, Playfair Display et Source Sans 3, palette bordeaux et rouge, fond crème), relevée dans ses feuilles de style. Les tokens sont déclarés une seule fois dans `frontend/src/styles/globals.css`.

Écarts assumés :

- icônes Hugeicons ;
- mode sombre par bouton, clair par défaut, comme sur lerevenu.com ;
- vues, sondages, événements et classement non repris, faute de données réelles derrière ;
- contenu requis sans minimum de 20 caractères (règle du sujet).
